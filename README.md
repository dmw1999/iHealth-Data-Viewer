# iHealth-Data-Viewer
iHDV - iHealth Data Viewer (iHealth Nexus Wireless Body Composition Scale) - A Python Tkinter GUI that allows you to import a .csv export of your data collected on an iHealth Nexus Scale from the iHealth MyVitals app and view the data, filter it, graph it, and save images of the graphs.

Version 1.0: [https://github.com/dmw1999/iHealth-Data-Viewer/releases/tag/V1.0](url)
